# Brand Rules

## Logo

The canonical logo is at `public/brand/subzero-metrix-logo.png`.

**Immutable rule:** Use the exact supplied logo without any modification. Do not:
- Redraw, recolor, or regenerate it
- Crop out brand elements
- Alter typography or simplify it
- Create alternate versions
- Replace it with text
- Allow vendor logos to become the primary brand

Use this logo as the canonical navigation, hero, social-image, and footer brand asset.
