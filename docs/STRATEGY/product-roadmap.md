# SubZeroMetrix Product Roadmap

## Vision

A contractor business launch and readiness platform for tradespeople — HVAC, Electrical, Plumbing, and beyond. Helps users assess readiness, receive a score, follow a personalized roadmap, and connect with vendor/affiliate resources.

## Build Priorities

1. **Stability** — keep existing features working
2. **Homepage + brand messaging** — clean, direct, field-tested tone
3. **Contractor readiness assessment** — scored quiz with phase output
4. **Scoring logic** — weighted scoring system per trade
5. **Roadmap/dashboard** — personalized progress tracker
6. **Supabase auth/database** — user accounts and score persistence
7. **Stripe payment flow** — gated report access
8. **Vendor/affiliate marketplace** — curated resource links with tracking

## Target Users

- HVAC technicians
- Electricians
- Plumbers
- Skilled tradespeople considering business ownership
- Early-stage contractors, day 0 through year 3

## Brand Voice

Practical, direct, field-tested, trustworthy. No corporate fluff, no vague startup language.

## Current Stack

- Next.js (App Router)
- Vercel deployment
- Supabase (auth + database)
- Stripe (payments)
- Tailwind CSS
