# SubZeroMetrix Project Brief

## Parent Brand
The Modern Trades Mentor

## Product Vision
SubZeroMetrix is a contractor business launch/readiness platform. It helps tradespeople assess whether they are ready to start a contracting business, receive a readiness score, follow a roadmap, and eventually connect with vendor/affiliate resources and trade-specific platforms.

## Target Users
- HVAC technicians
- Electricians
- Plumbers
- Skilled tradespeople considering business ownership
- Early-stage contractors from day 0 through year 3

## Core Product Goals
1. Contractor readiness assessment
2. Business launch scoring system
3. Personalized roadmap
4. Dashboard for progress tracking
5. Vendor/affiliate marketplace
6. Future trade-specific platforms for HVAC, Electrical, Plumbing, and other trades

## Current Stack
- Next.js
- Vercel deployment
- Supabase planned/used for auth and database
- Stripe planned/used for payments

## Brand Feel
Modern, practical, field-tested, clean, trustworthy, and built for real tradespeople.

Avoid:
- Corporate fluff
- Overly vague startup language
- Unnecessary rewrites
- Breaking working features

## Build Priorities
1. Keep the app stable
2. Improve homepage and brand messaging
3. Build contractor readiness assessment
4. Create scoring logic
5. Build roadmap/dashboard
6. Add Supabase auth/database
7. Add Stripe payment flow
8. Prepare vendor/affiliate marketplace
