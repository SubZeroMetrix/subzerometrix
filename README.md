# SubZero Metrix

Affiliate software comparison platform by SubZero Metrix LLC.

Compare software for websites, email, automation, ecommerce, newsletters, SEO, and online-business growth.

## Stack

- Next.js 14 (App Router, TypeScript, React 18)
- Tailwind CSS
- Supabase (auth, database, RLS)
- Stripe (future products only)
- Vercel deployment

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run lint
npm run typecheck
```

## Environment

Copy `.env.example` to `.env.local` and fill in your values. See `docs/ENVIRONMENT.md` for details.
